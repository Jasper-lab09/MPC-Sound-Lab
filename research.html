Research

Ongoing investigations into the relationships between sound, mathematics, and perception. This page documents the studio's research directions, methodology, and open questions.

Directions3 StatusActive
§ 01 Research Directions
Direction A — Signal Analysis

How can we make the invisible structure of sound visible and understandable? The Sound Visualizer module explores real-time frequency analysis, pitch detection, and harmonic decomposition using browser-native APIs.

X[k] = Σn=0N-1 x[n] · e-2πi·k·n/N

Key questions: How does FFT size affect the trade-off between time and frequency resolution? How do window functions influence spectral leakage? Can we reliably detect harmonic structures in real-time?

Direction B — Mathematical Composition

Can mathematical structures generate musically meaningful patterns? The Music Generator module investigates Fibonacci sequences, Euclidean rhythms, and harmonic series as compositional tools.

E(n, m) distributes n hits across m steps maximally evenly

Key questions: What makes Euclidean rhythms sound "good"? How does the golden ratio relate to musical aesthetics? Can probability-based generation maintain stylistic coherence?

Direction C — Sound-to-Visual Translation

Can audio information be faithfully translated into visual patterns for Deaf and hard-of-hearing users? The Accessibility module explores cross-modal perception, sound classification, and customizable visual feedback.

V = M · F + B
F = feature vector, M = mapping matrix, B = user bias

Key questions: Which acoustic features best discriminate sound categories? How do visual patterns map to perceived sound qualities? What are the honest limitations of visual translation?

§ 02 Methodology

First principles. Every tool is built from the ground up — a custom radix-2 FFT implementation, not a library call. This ensures we understand every step of the signal processing pipeline and can explain it to users.

Browser-native. All processing runs locally using Web Audio API and Canvas 2D. No servers, no data collection, no cloud dependencies. The entire lab works offline once loaded.

Transparent limitations. We document what our tools can and cannot do. dBFS is not dB SPL. Bin spacing is not frequency resolution. Visual translation is not hearing. Honesty about limitations is a research principle, not just a disclaimer.

Reproducible experiments. Every experiment has explicit parameters, step-by-step instructions, and A/B comparison capture. Results can be verified by anyone with a browser and microphone.

§ 03 Open Questions
01
Can real-time harmonic analysis be made reliable enough for educational use?
Current detection requires 5% relative amplitude and integer-multiple alignment. noisy signals produce false positives. Can we improve the reliability scoring without increasing latency?
02
What is the minimum feature set for useful sound classification?
Spectral centroid, ZCR, and spectral flux capture timbral qualities but miss temporal structure. How many features are needed for reliable speech/music/noise discrimination?
03
Do Euclidean rhythms generalize across cultural traditions?
E(3,8) produces tresillo (Cuban), E(2,3) produces habanera (Cuban/African). But does mathematical evenness always correlate with musical preference, or is it culturally conditioned?
