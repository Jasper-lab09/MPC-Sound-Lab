02 Mathematical Foundation
Sound Classification Features

Classifying sound into categories requires extracting numerical features from the audio signal:

Spectral centroid (brightness)
SC = Σ fk·|X[k]| / Σ|X[k]|
Zero-crossing rate (noisiness)
ZCR = (1/N) · #{sign changes in x[n]}
Spectral flux (onset detection)
SF = Σ (|X[k](t)| - |X[k](t-1)|)²

These features form a vector that can be compared against category prototypes using distance metrics or machine learning classifiers.

Pattern Mapping

Each sound category maps to a distinct visual pattern:

Speech → horizontal bands (formant structure)
Music → structured geometric patterns
Noise → scattered particle field
Beat → pulsing concentric rings
Silence → calm minimal state

The mapping function transforms the feature vector into visual parameters:

V = M · F + B

where F is the feature vector, M is the mapping matrix, and B is the user customization bias.

03 Physical Foundation

Cross-modal perception. The human brain processes sensory information in specialized cortical areas, but cross-modal connections exist. The visual cortex can learn to interpret patterns that correspond to auditory events — this is the principle behind visual alerts, closed captioning, and visual music.

Vocal tract acoustics. Speech sounds are distinguished by formant frequencies — resonant peaks determined by the shape of the vocal tract. Vowels have stable formant patterns; consonants produce transient bursts or noise. These acoustic differences are visible in a spectrogram, which means they can also be translated into visual patterns without requiring the listener to hear them.

Why visual translation works. Sound is fundamentally a time-varying signal. Vision excels at detecting spatial patterns and temporal changes. By mapping frequency to spatial position and amplitude to brightness/color, we create a visual representation that preserves the information-bearing dimensions of sound. This does not replicate hearing, but it can convey the presence, category, and temporal structure of acoustic events.

04 Experiments and Findings
01
Planned: Speech vs. Music Classification
Speak normally, then play music. The system should distinguish them by spectral flatness (speech has variable spectral entropy, music has harmonic structure) and ZCR patterns (speech varies rapidly, music is more consistent).
Status: Awaiting implementation
02
Planned: Sudden Sound Detection
Test detection of sudden sounds (door slam, hand clap) using spectral flux. These events produce a rapid change in frequency content that should trigger an immediate, high-contrast visual notification.
Status: Awaiting implementation
03
Planned: Customizable Pattern Sensitivity
Users adjust detection thresholds and visual feedback styles (color, intensity, pattern type) to match their visual sensitivity and preferences. This tests whether personalization improves the usability of visual sound feedback.
Status: Awaiting implementation
04
Planned: Limitation Study
Document what the system can and cannot detect. Quiet sounds, distant sounds, and sounds with similar spectral profiles may be missed or misclassified. This honest assessment is essential for setting appropriate user expectations.
Status: Awaiting implementation
